# Animal Queue

A C++ project that implements an animal clinic queue using a linked list and object-oriented programming.

## Overview

This project simulates an animal clinic waiting line where animals can be added to the queue, inserted after a specific animal, and removed from the front of the queue.

## Concepts Used

- C++
- Object-Oriented Programming (OOP)
- Classes and inheritance
- Pointers
- Linked lists
- Dynamic memory allocation
- Queue operations
- Polymorphism

## Features

- Add animals to the end of the queue
- Insert an animal after a specified animal
- Remove the animal at the front of the queue
- Display the current order of animals in the clinic queue
- Support multiple animal types, including turtles, cats, dogs, and cows
